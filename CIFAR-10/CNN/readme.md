# CIFAR-10 Classification with MobileNetV2

This project performs handwritten digit classification on the CIFAR-10 dataset using MobileNetV2 with transfer learning and fine-tuning.

Due to GitHub's file size limits, the full `train.npz` file is not included in this repository. [Download`train.npz`](https://drive.google.com/file/d/1HLS2DqfLUL0y2R378E3e9e4MICVjvlRO/view?usp=sharing)


## Setup Instructions

1. **Create the Conda environment**

Make sure you have Conda installed. Then run:

```bash
conda env create -f environment.yml
conda activate MNIST
```

2. **Run the notebook**

Open the notebook in Jupyter, VS Code, or your preferred IDE and run all cells in **Zvenyika_N_CSE347_Project.ipynb** to train and evaluate the model.
