# Iyer Classification with Custom 1D CNN

This project performs multi-class classification on the Iyer gene expression dataset using a custom 1D Convolutional Neural Network (CNN). The model is trained from scratch and evaluated using cross-validation and a held-out test set.

## Setup Instructions

1. **Create the Conda environment**

Make sure you have Conda installed. Then run:

```bash
conda env create -f environment.yml
conda activate MNIST
```

2. **Run the notebook**

Open the notebook in Jupyter, VS Code, or your preferred IDE and run all cells in **Zvenyika_N_CSE347_IYER_Classification.ipynb** to train and evaluate the model.
