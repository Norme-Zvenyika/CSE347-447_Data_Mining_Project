# CSE347/447 Final Project

## Project Overview

This project evaluates the performance of three classification algorithms—Convolutional Neural Networks (CNN), Support Vector Machines (SVM), and XGBoost—across three datasets with varying characteristics. The goal is to compare how each model performs on image and tabular data, highlighting their strengths and limitations.

## Algorithms Used

* **Convolutional Neural Networks (CNN) by Norman Zvenyika:**
  Applied using both transfer learning and fine-tuning techniques for image-based datasets.

* **Support Vector Machines (SVM) by Prince Omuyeh:**
  A traditional kernel-based classifier evaluated on appropriate preprocessed data.

* **XGBoost by Sharmili Rudraraju:**
  A gradient-boosted tree-based model used for both image data (after flattening) and tabular data.

## Datasets

* **MNIST**
  Handwritten digit images (28x28 grayscale).

* **CIFAR-10**
  Color images (32x32) categorized into 10 object classes.

* **Iyer Dataset**
  Gene expression dataset containing tabular numerical features.
